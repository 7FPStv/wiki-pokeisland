# Objets spéciaux

PokeIsland ajoute une série d'objets qui n'existent pas dans Cobblemon de base. Ils se gagnent en [raid](raid.md), en [Battle Factory](battle-factory.md), dans les coffres, via les [récompenses Pokédex](recompenses-pokedex.md) ou à la [Boutique](boutique.md).

{% hint style="success" %}
**Comment les utiliser :** prends l'objet en main et fais un **clic droit directement sur le Pokémon visé**. Pas de menu à ouvrir.
{% endhint %}

***

## Les cristaux

| Objet | Effet |
| ------------------------ | ------------------------------------------------ |
| **Cristal IV Parfait** | Passe **toutes** les IV du Pokémon à 31 |
| **Cristal de Niveau** | Passe le Pokémon **niveau 100** |
| **Cristal EV PV** | Met les EV de PV à **252** |
| **Cristal EV Attaque** | Met les EV d'Attaque à 252 |
| **Cristal EV Défense** | Met les EV de Défense à 252 |
| **Cristal EV Att. Spé.** | Met les EV d'Attaque Spéciale à 252 |
| **Cristal EV Déf. Spé.** | Met les EV de Défense Spéciale à 252 |
| **Cristal EV Vitesse** | Met les EV de Vitesse à 252 |
| **Cristal de Reproduction** | +1 reproduction disponible sur le Pokémon |

{% hint style="info" %}
Les Cristaux EV respectent le plafond total de **510 EV**. Tu ne peux donc pas en poser six sur le même Pokémon : au bout de deux, tu es à 504 et il ne reste presque plus de marge.
{% endhint %}

***

## Shiny

| Objet | Effet |
| ---------------------- | -------------------------------------------------- |
| **Pierre Shiny** | Rend un Pokémon que tu possèdes **shiny** |
| **Shiny Master Ball** | Capture **garantie** + le Pokémon capturé est shiny |

{% hint style="danger" %}
La **Pierre Shiny** ne fonctionne **pas** sur les Légendaires, les Fabuleux, les Ultra-Chimères, les Paradoxes ni les Pokémon restreints.

La **Shiny Master Ball**, elle, fonctionne sur tout — y compris les Légendaires. C'est l'un des objets les plus rares du serveur.
{% endhint %}

## Les consommables PokeIsland

| Objet | Effet |
| --------------------------- | --------------------------------------- |
| **Petite recharge d'énergie** | Restaure un peu d'[énergie](energie.md) |
| **Recharge d'énergie** | Restaure de l'énergie |

| **Ticket de Safari** | Donne accès à un [Safari](pokeworld/safari.md) |

## Les œufs

| Œuf | Ce qu'il donne |
| ---------------- | --------------------------------- |
| **Œuf Pokémon** | Un Pokémon aléatoire |
| **Œuf Céleste** | Un Pokémon de meilleure qualité |
| **Œuf Shiny** | Un Pokémon shiny |
| **Œuf Légendaire** | Un Pokémon légendaire |
| **Œuf Fusion** | Un Pokémon fusionné |

***

## Les outils cosmétiques

| Outil | Effet |
| --------------------- | ------------------------------------------------------------ |
| **Pioche large** | Casse le bloc visé **et les 8 blocs autour** (grille 3×3) |
| **Houe replanteuse** | Récolte une zone **3×3** de cultures mûres et **les replante** automatiquement |

{% hint style="info" %}
La houe replanteuse consomme une graine par culture replantée : garde-en dans ton inventaire. Elle gère le blé, les carottes, les pommes de terre, les betteraves, les verrues du Nether, le cacao, les torchflowers, ainsi que les baies sucrées et les lianes lumineuses.

Ces deux outils **respectent les protections** : ils ne casseront rien sur une île qui n'est pas la tienne, ni dans une arène.
{% endhint %}

## Les clés de coffre

| Clé | Coffre associé |
| -------------- | -------------- |
| **Clé Vote** | Coffre Vote |
| **Clé Dresseur** | Coffre Dresseur |
| **Clé Expert** | Coffre Expert |
| **Clé Champion** | Coffre Champion |

Les clés Vote s'obtiennent en [votant](../tutoriel/vote-and-gagne.md), les clés Événement lors des [chasses](chasse.md) rares, les autres via la [Boutique](boutique.md) et les récompenses de progression.

***

## Restrictions générales

* Un objet ne peut être utilisé que sur un Pokémon **qui t'appartient**.
* Impossible de les utiliser **pendant un combat**.
* Impossible de les utiliser **sur un œuf**.
* L'objet est **consommé** à l'usage.
