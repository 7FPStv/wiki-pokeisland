# Récompenses Pokédex

Chaque tranche de **10 % de Pokédex complété** débloque une récompense à récupérer. <kbd>**/dex**</kbd>

Le compteur avance à chaque **nouvelle espèce** capturée : c'est la diversité qui paye, pas la quantité.

***

## Les paliers

| Complétion | Récompenses |
| ---------- | -------------------------------------------------------------- |
| **10 %** | 1 Méga Gems aléatoire + 3 Œufs Pokémon |
| **20 %** | 1 Œuf Pokémon Céleste |
| **30 %** | 1 Œuf Shiny |
| **40 %** | 1 Méga Gems aléatoire + 1 Œuf Céleste + 1 Œuf Shiny |
| **50 %** | 1 Œuf Céleste |
| **60 %** | 1 Œuf Shiny |
| **70 %** | 1 Méga Gems aléatoire + 1 Œuf Céleste |
| **80 %** | **Grade Radiant pendant 7 jours** + 1 Œuf Shiny |
| **90 %** | **1 Œuf Légendaire** + 1 Œuf Céleste + 1 Œuf Shiny |
| **99 %** | **1 Œuf Fusion** |

{% hint style="info" %}
Les récompenses ne sont **pas** données automatiquement : il faut passer par `/dex` pour les réclamer. Un palier déjà réclamé ne peut pas l'être une seconde fois.
{% endhint %}

***

## Les types d'œufs

| Œuf | Ce qu'il donne |
| ---------------- | ---------------------------------------------- |
| **Pokémon** | Un Pokémon aléatoire |
| **Céleste** | Un Pokémon aléatoire, avec **5 % de chance d'être shiny** |
| **Shiny** | Un Pokémon shiny |
| **Légendaire** | Un Pokémon légendaire |
| **Fusion** | Un Pokémon fusionné (voir [Fusionneur](fusionneur.md)) |

***

## Le Pokédex compte aussi ailleurs

Ta complétion de Pokédex n'ouvre pas que ces paliers :

* elle donne de l'**XP Dresseur** aux paliers 25 %, 50 %, 75 % et 100 % (respectivement 500, 2 000, 3 500 et 5 000 XP) ;
* elle est une **condition du [Rebirth](dresseur.md#le-rebirth-prestige)** — il te faut 75 % minimum ;
* elle s'affiche sur ta **fiche joueur**, visible par tout le monde dans le chat.
