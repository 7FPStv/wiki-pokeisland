# MiniBoss

Des **Pokémon Boss** apparaissent aléatoirement à proximité des joueurs. Tu les affrontes en combat, et ils lâchent des récompenses à la hauteur de leur rareté.

{% hint style="success" %}
**Les MiniBoss se capturent.** Après l'avoir vaincu, tu disposes de **3 tentatives** pour l'attraper. Le boss reste 2 minutes avant de disparaître.
{% endhint %}

***

## Les huit raretés

| Rareté | Chance d'apparition | Niveau |
| ------------------- | ------------------: | ------ |
| **Commun** | 37 % | 60 |
| **Rare** | 21 % | 100 |
| **Rare Méga** | 12 % | 100 |
| **Dynamax** | 10 % | 100 |
| **Téracristal** | 8 % | 100 |
| **Motisma** | 5 % | 100 |
| **Légendaire** | 4 % | 100 |
| **Légendaire Méga** | 2 % | 100 |

Les boss Méga, Dynamax et Téracristal utilisent réellement leur mécanique en combat : attends-toi à voir la barre de vie remonter d'un coup.

***

## Quand ils apparaissent

La fréquence d'apparition et tes chances de capture dépendent du **moment de la semaine**.

| Créneau | Fréquence | Bonus de capture |
| ----------------------- | ----------------- | ---------------- |
| Semaine — jour (8h-20h) | Normale | ×1 |
| Semaine — nuit (20h-8h) | Deux fois moindre | **×1,2** |
| Week-end — jour | Normale | **×1,5** |
| Week-end — nuit | Deux fois moindre | **×2** |

Le week-end démarre le **vendredi 18h** et se termine le **dimanche 23h59**.

{% hint style="info" %}
Il y a moins de boss la nuit, mais ceux qui apparaissent sont bien plus faciles à capturer. Le meilleur créneau du serveur, c'est la **nuit du week-end** : chances doublées.
{% endhint %}

***

## Chances de capture

Après ta victoire, ta chance d'attraper le boss dépend de sa rareté. Voici les valeurs de base (semaine, jour), à multiplier par le bonus du créneau :

| Rareté | Chance de base | Nuit week-end (×2) |
| ------------------- | -------------: | -----------------: |
| Commun | 1 % | 2 % |
| Rare | 2 % | 4 % |
| Rare Méga | 3 % | 6 % |
| Dynamax | 3 % | 6 % |
| Motisma | 3 % | 6 % |
| Téracristal | 4 % | 8 % |
| Légendaire | 8 % | 16 % |
| **Légendaire Méga** | 12 % | **24 %** |

{% hint style="warning" %}
Ce sont des chances par **tentative**, et tu en as 3. Aucune capture n'est garantie, même en Légendaire Méga.
{% endhint %}

***

## Les règles du combat

* **5 boss actifs maximum** sur le serveur en même temps.
* Un boss apparaît entre **3 et 10 blocs** de toi.
* Tu as **5 tentatives** de combat sur un même boss. Après ça, il prend la fuite.
* Un boss disparaît au bout de **10 minutes** s'il n'est pas vaincu.
* Rester **inactif 5 minutes** met fin au combat.
* Une **boss bar** s'affiche dans un rayon de 50 blocs.

Les apparitions et les victoires sont annoncées dans le chat.

## Les Motisma

Les boss **Motisma** sont un cas à part : chaque forme lâche son propre appareil, avec **20 %** de chance.

| Forme | Objet lâché |
| --------------- | ----------------------- |
| Motisma Chaleur | Four Motisma |
| Motisma Lavage | Machine à laver Motisma |
| Motisma Froid | Réfrigérateur Motisma |
| Motisma Hélice | Ventilateur Motisma |
| Motisma Tonte | Tondeuse Motisma |

{% hint style="success" %}
Ces appareils permettent de changer la forme de **ton propre Motisma**. C'est la seule façon de les obtenir.
{% endhint %}
