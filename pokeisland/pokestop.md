# PokéStop

Les **PokéStops** sont disséminés dans le monde. Tu en actives un, il te donne **une** récompense, puis il se met à recharger. Il y en a **30** en tout, chacun avec son propre compte à rebours d'**une heure**.

{% hint style="success" %}
Les 30 rechargements sont **indépendants**. Rien ne t'empêche d'enchaîner plusieurs stops à la suite, puis de refaire le tour une heure plus tard.
{% endhint %}

***

## Comment marche le tirage

Deux tirages successifs à chaque stop :

1. **La rareté** est tirée au sort selon les chances ci-dessous.
2. **Une seule récompense** est ensuite tirée au hasard dans la liste de cette rareté.

| Rareté | Chance |
| -------------- | -----: |
| **Commune** | 60 % |
| **Rare** | 25 % |
| **Épique** | 12 % |
| **Légendaire** | 3 % |

{% hint style="warning" %}
Les récompenses **ne se cumulent pas** : tu repars avec une ligne de la liste, et une seule.
{% endhint %}

***
