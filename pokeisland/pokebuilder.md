# PokéBuilder

Le **PokéBuilder** est l'outil qui te permet de **modifier tes Pokémon** : monter leurs statistiques, changer leur nature, leur talent, leur apparence. <kbd>**/pokebuilder**</kbd>

Tout se paye en **jetons PokéBuilder**, une monnaie dédiée.

***

## Où trouver des jetons

Les jetons ne s'achètent pas avec des PokéCoins. Tu les gagnes en jouant :

| Source | Gain |
| ------------------------- | ---------------- |
| [Chasse](chasse.md) — Commun | 1 jeton |
| [Chasse](chasse.md) — Peu commun | 2 jetons |
| [Chasse](chasse.md) — Rare | 3 jetons |
| [Chasse](chasse.md) — Ultra Rare | 4 jetons |
| Niveaux de [Dresseur](dresseur.md) | 10 à 30 jetons par niveau |
| [Parchemins de mission](mission.md) | 1 / 3 / 8 / 15 jetons selon la rareté |

***

## Les modules et leurs prix

| Module | Ce que ça fait | Prix en jetons |
| ------------------- | -------------------------------- | ------------------ |
| **Niveau** | +1 niveau | 20 |
| **Niveau (baisse)** | −1 niveau | 20 |
| **IV** | +1 point d'IV sur une stat | 3 |
| **IV (baisse)** | −1 point d'IV | 3 |
| **EV** | +1 EV sur une stat | 1 |
| **EV (baisse)** | −1 EV | 1 |
| **Nature** | Change la nature | 200 |
| **Talent** | Change le talent | 200 |
| **Sexe** | Change le sexe | 150 |
| **Poké Ball** | Change la ball d'origine | 100 |

***

## Les limites

Ce sont les mêmes plafonds que le jeu de base — on ne peut pas dépasser les règles Pokémon :

| Limite | Valeur |
| ------------------------- | ------ |
| Niveau maximum | 100 |
| IV maximum par statistique | 31 |
| IV total maximum | 186 |
| EV total maximum | 510 |
| EV maximum par statistique | 252 |
| IV ajoutés par jour | 186 points maximum |
| EV ajoutés par jour | 510 maximum |

Le module de talent n'autorise que les **talents légaux** de l'espèce : pas question de coller Intimidation sur n'importe quoi.

***

## Ce qui est interdit

{% hint style="danger" %}
**Métamorph** ne peut pas être amélioré avec les modules. Et le PokéBuilder ne rend **pas** un Pokémon shiny.
{% endhint %}

***

## Méthode conseillée

1. Choisis d'abord ton Pokémon **définitif** — inutile de dépenser sur un intermédiaire.
2. Fixe la **nature** en premier : c'est elle qui décide de ton profil (physique, spécial, rapide…).
3. Monte les **IV** des stats qui comptent. Monter les six à 31 est cher : concentre-toi sur 3 ou 4.
4. Répartis les **EV** ensuite. Un profil classique, c'est 252 / 252 / 4.

{% hint style="success" %}
Pour les EV, tu peux aussi passer par les **Safaris EV** ([Rock Safari](pokeworld/safari.md) et Fire Safari), qui te les font gagner en jouant plutôt qu'en jetons.
{% endhint %}
