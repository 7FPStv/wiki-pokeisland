# Halloween

Pour **Halloween**, seize Pokémon revêtent leur costume d'Halloween. Tu peux les affronter en mini-boss, les obtenir dans la **Box d'Halloween** et dépenser ta **Monnaie Halloween** dans une boutique dédiée. `/halloween`

{% hint style="info" %}
Au raid, à la Tour de combat et à la Battle Factory, tu reçois désormais **1 Monnaie Halloween en plus** de ta Monnaie Éclipse.
{% endhint %}

***

## En bref

| Activité | Ce que tu gagnes | Où |
| --------------------------------------------------------- | ------------------------------------------- | -------------- |
| [Boss de raid](boss.md) de 20h | 1 Monnaie Halloween par participation | Spawn |
| [Tour de combat](../tour-de-combat.md) | 1 Monnaie Halloween par tour terminée | Spawn |
| [Battle Factory](../battle-factory.md) | 1 Monnaie Halloween à 9 victoires cumulées | Spawn |
| [Mini-boss](../ressources/miniboss.md) d'Halloween | 1 Monnaie Halloween par boss vaincu, et du butin | Monde Ressource |
| **Box d'Halloween** | 1 peluche et 1 Pokémon d'Halloween par ouverture | Spawn |
| **Boutique Halloween** | Clés citrouille, cristaux, œufs, Pierre Shiny… | `/halloween` |

***

## Les Pokémon d'Halloween

Seize Pokémon ont une forme d'Halloween (rendus 3D sur la page [Pokémon Halloween 2026](../../cobblemon/pokemon/halloween-2026.md)) : **Absol**, **Zoroark**, **Miascarade**, **Spiritomb**, **Démolosse**, **Feunard**, **Momartik**, **Goupelin**, **Bruyverne**, **Nostenfer**, **Ténéfix**, **Corboss**, **Noctunoir**, **Malamandre**, et les légendaires **Darkrai** et **Lunala**.

Tu les affrontes en **mini-boss**, mais ceux-ci ne se capturent pas : pour en obtenir un, ouvre la **Box d'Halloween**.

***

## Gagner de la Monnaie Halloween

| Source | Gain | Fréquence |
| -------------------------------------------------- | :--: | ---------------------------------------- |
| Participer au **boss de raid** (un seul coup suffit) | 1 | Un raid par jour, à 20h |
| Terminer la **Tour de combat**, quelle que soit la difficulté | 1 | Une tentative toutes les 24 heures |
| Atteindre **9 victoires** à la **Battle Factory** (fin de manche 3) | 1 | Une série toutes les 24 heures |
| Vaincre un **mini-boss d'Halloween** | 1 | Sans limite, selon les apparitions |

{% hint style="info" %}
Tu ne reçois **aucun message** quand la monnaie arrive. Ton solde s'affiche dans la boutique `/halloween`.
{% endhint %}

***

## Les mini-boss d'Halloween

Dans le **monde Ressource**, les [mini-boss](../ressources/miniboss.md) ont une nouvelle rareté : **Halloween**. Environ **un mini-boss sur cinq** (19,9 %) est un Pokémon d'Halloween, tiré au hasard parmi les seize. Ils sont **niveau 100**, avec des sets de combat travaillés.

Les règles d'apparition et de combat sont celles de tous les mini-boss : voir la page [MiniBoss](../ressources/miniboss.md).

{% hint style="danger" %}
Les mini-boss d'Halloween **ne se capturent pas** : tu les combats pour leurs récompenses uniquement.
{% endhint %}

### Récompenses

Chaque victoire rapporte **systématiquement** :

* **1 Monnaie Halloween** ;
* **260 XP Dresseur** ;
* **7 500 PokéCoins**.

Puis chaque ligne du butin est tirée indépendamment : tu peux repartir avec plusieurs objets, ou aucun.

| Chance | Récompense |
| ------ | ------------------------------------------------------- |
| 65 % | 1 CT aléatoire |
| 55 % | 1 Ticket Safari |
| 45 % | 1 Œuf Pokémon |
| 40 % | 1 Méga Gems aléatoire (et 5 % d'en obtenir une seconde) |
| 10 % | 1 Œuf Céleste |
| 9 % | 1 Œuf Shiny |
| 5 % | 1 Parchemin de quête Rare |
| 3 % | 1 Item Légendaire aléatoire |
| 1 % | 1 Œuf Légendaire |

## La Box d'Halloween

La **Box d'Halloween** est un coffre-citrouille animé posé au **Spawn**, aux coordonnées **-27 107 7**. Pour l'ouvrir, il te faut une **Clé citrouille**.

* **Clic gauche** sur la box : tu inspectes son contenu et ton nombre de clés.
* **Clic droit** : tu l'ouvres (une clé par ouverture).

{% hint style="success" %}
**Une ouverture = deux lots** : une **peluche d'Halloween** et un **Pokémon d'Halloween**. Chacun a environ **1 chance sur 11** d'être shiny.
{% endhint %}

### Les chances

Les deux colonnes ont exactement les mêmes chances.

| Lot | Chance (chacun) |
| ---------------------------------------------- | --------------: |
| Une des 14 espèces classiques | 6,34 % |
| Darkrai ou Lunala | 1,06 % |
| Une des 14 espèces classiques, **shiny** | 0,63 % |
| **Darkrai ou Lunala shiny** | **0,11 %** |

Les Pokémon obtenus portent leur **forme d'Halloween**. Les peluches se posent comme des blocs de décoration.

## La boutique Halloween

La boutique `/halloween` se paie en **Monnaie Halloween**. Elle est ouverte sur le **Spawn**, les **îles** et le **monde Ressource**.

| Article | Prix | Limite |
| ------------------------------------------------- | ---: | :-------: |
| **Clé citrouille** | 50 | 3 |
| Super Bonbon ×5 | 3 | — |
| Ticket Safari | 5 | — |
| CT aléatoire | 8 | — |
| Cristal EV (PV, Attaque, Défense, Att. Spé., Déf. Spé. ou Vitesse) | 5 | 12 par stat |
| Cristal de Niveau | 10 | 10 |
| Cristal IV Parfait | 18 | 6 |
| Méga Gems aléatoire | 25 | 3 |
| Œuf Shiny aléatoire | 35 | 2 |
| Œuf Céleste aléatoire | 50 | 1 |

{% hint style="warning" %}
Les limites sont **définitives**, pas quotidiennes : elles valent pour toute la durée de l'événement, et **sur tous les serveurs à la fois**. Un tiret signifie que l'article est illimité.
{% endhint %}

## Commandes

| Commande | Description |
| ------------- | ------------------------------------------ |
| `/halloween` | Ouvre la boutique Halloween et affiche ton solde |
| `/raid` | Informations sur le boss de raid |
| `/tour` | Ouvre la Tour de combat |
| `/bf` | Ouvre la Battle Factory |

{% hint style="info" %}
**Conseils**

* Fais ton **raid**, ta **Tour** et ta **Battle Factory** chaque jour : jusqu'à 3 Monnaies Halloween par jour.
* Le **monde Ressource** est le seul endroit où tu croiseras les mini-boss d'Halloween : c'est la source illimitée de monnaie.
* N'oublie pas tes **3 Clés citrouille** de la boutique Halloween : elles se paient en Monnaie Halloween, pas en gems.
{% endhint %}
