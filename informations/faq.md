# FAQ

<sup><mark style="color:$info;">Les réponses aux questions qui reviennent le plus souvent. Clique sur une question pour dérouler la réponse.<mark style="color:$info;"></sup>

***

## Avant de jouer

<details>

<summary><strong>Faut-il acheter Minecraft pour jouer sur PokeIsland ?</strong></summary>

Oui. PokeIsland tourne sur **Minecraft Java Edition**, qui est un jeu payant, acheté une seule fois et lié à un compte Microsoft.

> * Le serveur n'accepte **que les comptes officiels**. Un compte non authentifié ne peut pas se connecter.
> * Une fois le jeu acheté, tout le reste est installé par notre launcher, sans achat supplémentaire.
> * Si tu viens d'acheter le jeu, lance-le **une première fois** avec le launcher officiel Minecraft pour créer ton pseudo. Tant qu'aucun pseudo n'existe, aucun launcher ne peut te connecter.

<sup>Pour vérifier ce que possède ton compte : <a href="https://www.minecraft.net/msaprofile/mygames">minecraft.net/msaprofile/mygames</a></sup>

</details>

<details>

<summary><strong>Puis-je jouer sur console, téléphone ou tablette ?</strong></summary>

Non. Ces supports utilisent **Minecraft Bedrock Edition**, qui est un jeu différent et incompatible avec PokeIsland.

<table><thead><tr><th width="240">Édition</th><th width="150">Compatible</th><th>Supports</th></tr></thead><tbody><tr><td><strong>Java Edition</strong></td><td>Oui</td><td>Ordinateur (Windows, macOS)</td></tr><tr><td><strong>Bedrock Edition</strong></td><td>Non</td><td>Console, téléphone, tablette, Windows Store</td></tr></tbody></table>

Posséder Bedrock ne donne pas accès à Java : ce sont deux achats distincts. Et non, une version Bedrock du serveur n'est pas prévue.

</details>

<details>

<summary><strong>Le launcher fonctionne-t-il sur Mac et sur Linux ?</strong></summary>

Le launcher est distribué pour **Windows** et **macOS**. Il n'existe **pas de version Linux**.

Tu télécharges la version qui correspond à ton système sur [pokeisland.fr/jouer](https://pokeisland.fr/jouer/).

</details>

<details>

<summary><strong>Dois-je installer Cobblemon moi-même ?</strong></summary>

Non, et il vaut mieux ne pas essayer. Le **launcher PokeIsland installe tout automatiquement** : la bonne version de Minecraft, Fabric, le mod Cobblemon, ses addons et nos mods maison.

> * Tu n'as **aucun fichier à télécharger ni à déplacer** à la main.
> * Le launcher vérifie les fichiers à chaque lancement et retélécharge ce qui manque ou ce qui est abîmé.
> * Une installation Cobblemon montée de ton côté ne pourra pas rejoindre le serveur : les versions ne correspondraient pas.

</details>

<details>

<summary><strong>Puis-je rejoindre le serveur avec une adresse IP ?</strong></summary>

Non. PokeIsland est accessible **uniquement via le launcher officiel**.

Le serveur utilise des mods précis, dans des versions précises. Le launcher garantit que ton jeu correspond exactement à ce que le serveur attend, ce qu'une connexion par adresse IP depuis le launcher Minecraft classique ne peut pas faire.

{% content-ref url="telechargement/" %}
[telechargement](telechargement/)
{% endcontent-ref %}

</details>

<details>

<summary><strong>Le launcher affiche une alerte de sécurité Windows, est-ce dangereux ?</strong></summary>

Non. Windows affiche cet avertissement pour **tout programme qu'il ne connaît pas encore**, et notre launcher est trop récent et trop peu téléchargé pour figurer dans sa liste. Ce n'est pas une détection de virus.

La marche à suivre, capture par capture, est détaillée ici :

{% content-ref url="../help/launcher.md" %}
[launcher.md](../help/launcher.md)
{% endcontent-ref %}

{% hint style="warning" %}
Télécharge toujours le launcher depuis [pokeisland.fr/jouer](https://pokeisland.fr/jouer/). Un fichier récupéré ailleurs n'est pas le nôtre, et là, la prudence est justifiée.
{% endhint %}

</details>

## Débuter en jeu

<details>

<summary><strong>Comment se passe le choix du starter ?</strong></summary>

À ta toute première connexion, tu arrives sur l'île du **Spawn** et tu choisis ton Pokémon de départ parmi les starters officiels de Cobblemon.

{% hint style="warning" %}
Ce choix est **définitif**. Les starters sont rares à trouver dans la nature : prends le temps de réfléchir avant de valider.
{% endhint %}

{% content-ref url="../tutoriel/premier-pas.md" %}
[premier-pas.md](../tutoriel/premier-pas.md)
{% endcontent-ref %}

</details>

<details>

<summary><strong>Comment obtenir mon île ?</strong></summary>

Depuis le point d'arrivée, avance tout droit jusqu'au panneau **« Saute »**, ou tape simplement la commande `/is create`.

Ton île est ta base, ton point de retour et ton espace de construction. Quelques commandes à connaître :

<table><thead><tr><th width="200">Commande</th><th>Ce qu'elle fait</th></tr></thead><tbody><tr><td><code>/is</code></td><td>Ouvre le menu de ton île</td></tr><tr><td><code>/is go</code></td><td>Te téléporte chez toi</td></tr><tr><td><code>/is invite</code> <code>Pseudo</code></td><td>Invite un ami sur ton île</td></tr><tr><td><code>/is upgrade</code></td><td>Améliore le niveau de l'île</td></tr></tbody></table>

{% content-ref url="../pokeisland/ile-joueurs.md" %}
[ile-joueurs.md](../pokeisland/ile-joueurs.md)
{% endcontent-ref %}

</details>

<details>

<summary><strong>Quelle commande faut-il retenir en priorité ?</strong></summary>

Une seule : **`/menu`**.

Elle regroupe toutes les interfaces importantes du serveur au même endroit. Tu n'as donc pas besoin de mémoriser les autres commandes pour t'en servir.

<table><thead><tr><th width="170">Interface</th><th>À quoi elle sert</th></tr></thead><tbody><tr><td><code>/pokeworld</code></td><td>La carte des îles à explorer</td></tr><tr><td><code>/is</code></td><td>La gestion de ton île</td></tr><tr><td><code>/rangs</code></td><td>Ta progression dans les rangs</td></tr><tr><td><code>/chasse</code></td><td>Les chasses de Pokémon</td></tr><tr><td><code>/boutique</code></td><td>La boutique en jeu</td></tr><tr><td><code>/vote</code></td><td>Voter et récupérer tes récompenses</td></tr></tbody></table>

</details>

<details>

<summary><strong>Pourquoi je n'arrive plus à capturer de Pokémon ?</strong></summary>

Il te manque très probablement de l'**énergie**. Sur PokeIsland, chaque Poké Ball lancée en consomme, et sans énergie, aucune capture n'est possible.

> * Ton énergie est plafonnée à **100** au départ, et remonte de **+1 par minute**.
> * Elle se recharge **même quand tu es déconnecté**.
> * Chaque passage de niveau dresseur restaure ton énergie à 100.
> * Une Poké Ball coûte 2 énergie, une Hyper Ball 5, et une **Master Ball 50** à elle seule.

{% hint style="info" %}
Pense à ton énergie **avant** de partir chasser un légendaire : une apparition ne dure que 15 minutes, et arriver à sec revient à regarder le Pokémon disparaître.
{% endhint %}

{% content-ref url="../pokeisland/energie.md" %}
[energie.md](../pokeisland/energie.md)
{% endcontent-ref %}

</details>

<details>

<summary><strong>Où aller après le Spawn ?</strong></summary>

Direction le **PokéWorld**, l'archipel de 8 îles qui structure toute l'aventure.

Depuis le Spawn, prends la route vers la droite en direction du dôme de l'arène. Un panneau **Vers l'aventure** t'indique la plage de départ : embarque sur le bateau vers **l'île Water**, la première du parcours.

Chaque île découverte est ensuite enregistrée dans ton menu `/pokeworld`.

{% content-ref url="../pokeisland/pokeworld/" %}
[pokeworld](../pokeisland/pokeworld/)
{% endcontent-ref %}

</details>

<details>

<summary><strong>Comment gagner mes premiers PokéCoins ?</strong></summary>

Quatre sources accessibles dès le début, sans rien avoir débloqué :

> * **Voter** pour le serveur avec `/vote`, tous les jours.
> * **Récupérer tes Rewards** de temps de jeu avec `/rewards`.
> * **Vendre tes ressources** au Marchand Shop ou via l'Œuf de Marchand.
> * **Chasser** les Pokémon demandés avec `/chasse` : c'est la source la plus rentable et la plus sous-estimée des débutants.

{% content-ref url="../pokeisland/economie/" %}
[economie](../pokeisland/economie/)
{% endcontent-ref %}

</details>

<details>

<summary><strong>À quoi sert le niveau de dresseur ?</strong></summary>

C'est le fil conducteur de ta progression. **Toutes tes actions sur le serveur** rapportent de l'EXP dresseur, et ton niveau conditionne ce que tu peux atteindre.

> * Il **débloque des arènes**, des zones et des paliers de difficulté.
> * Il **augmente ton énergie maximale**.
> * Il donne des **récompenses** à chaque palier, dont des recharges d'énergie dès le niveau 6.

{% content-ref url="../pokeisland/dresseur.md" %}
[dresseur.md](../pokeisland/dresseur.md)
{% endcontent-ref %}

</details>

<details>

<summary><strong>Puis-je jouer avec mes amis ?</strong></summary>

Oui, de plusieurs façons :

> * **Sur ton île** : invite-les avec `/is invite Pseudo`. Ils pourront construire et jouer avec toi selon les permissions que tu définis dans `/is permissions`.
> * **En combat** : affrontez-vous en duel, en Ranked 1v1 ou dans les arènes joueurs.
> * **En échange** : le GTS et les enchères permettent de s'échanger Pokémon et objets entre joueurs.

</details>
