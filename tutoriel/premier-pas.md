# Premier pas

Bienvenue sur PokeIsland ! Cette page te guide pas à pas depuis ta première connexion jusqu'à tes premiers combats.

---

## 1. Installer et rejoindre le serveur

PokeIsland est accessible uniquement via le **launcher officiel**. Il installe automatiquement Minecraft et le mod Cobblemon dans la bonne version — pas besoin de configurer quoi que ce soit manuellement.

## 2. Choisir ton starter

À ta première connexion, tu arrives sur l'île du **Spawn**. Avant de commencer ton aventure, tu dois choisir ton **Pokémon de départ** parmi les starters officiels de Cobblemon, couvrant les générations 1 à 9.

| Génération | Starters disponibles |
| --- | --- |
| Kanto (Gen 1) | Bulbasaur · Charmander · Squirtle |
| Johto (Gen 2) | Chikorita · Cyndaquil · Totodile |
| Hoenn (Gen 3) | Treecko · Torchic · Mudkip |
| Sinnoh (Gen 4) | Turtwig · Chimchar · Piplup |
| Unova (Gen 5) | Snivy · Tepig · Oshawott |
| Kalos (Gen 6) | Chespin · Fennekin · Froakie |
| Alola (Gen 7) | Rowlet · Litten · Popplio |
| Galar (Gen 8) | Grookey · Scorbunny · Sobble |
| Paldea (Gen 9) | Sprigatito · Fuecoco · Quaxly |

{% hint style="warning" icon="circle-info" %}
Ce choix est **définitif**. Les starters sont rares à trouver dans la nature — choisis bien !
{% endhint %}

## 3. Créer ton île

Une fois ton starter en poche, avance tout droit depuis le point d'arrivée jusqu'au panneau **« Saute »** et crée ton île personnelle. C'est ta base, ton point de retour et ton espace de jeu.

---

## 4. La commande essentielle : `/menu`

`/menu` est **la commande la plus importante** du serveur. Elle centralise toutes les interfaces clés du jeu en un seul endroit.

| Interface | Description |
| --- | --- |
| `/pokeworld` | Carte des îles du PokéWorld à explorer |
| `/is` | Gestion de ton île personnelle |
| `/rangs` | Consulter et progresser dans les rangs |
| `/chasse` | Système de chasse de Pokémon spécifiques |
| `/boutique` | Boutique en jeu |
| `/enchere` | Système d'enchères entre joueurs |
| `/vote` | Voter pour soutenir le serveur et gagner des récompenses |

{% hint style="info" icon="circle-info" %}
Toutes ces interfaces sont accessibles depuis `/menu` — tu n'as pas besoin de mémoriser chaque commande individuellement.
{% endhint %}

---

## 5. Partir à l'aventure

Le monde de PokeIsland s'articule autour du **PokéWorld** : un archipel de 8 îles à explorer, chacune avec ses arènes, ses safaris et ses secrets.

Pour débloquer ta première île, prends la route vers la droite en direction du dôme de l'arène depuis le Spawn. Un panneau **Vers l'aventure** t'indiquera la plage de départ — embarque sur un bateau en direction de **l'île Water**.

{% hint style="info" icon="circle-info" %}
Chaque île que tu découvres est enregistrée dans ton menu `/pokeworld`.
{% endhint %}

---

## 6. Le système de dresseur

Toutes tes actions sur le serveur te rapportent de l'**EXP dresseur** et font progresser ton niveau. C'est ce niveau qui débloque les arènes, les zones et les récompenses au fil de ton aventure.

* Capturer un Pokémon → `35 – 175 EXP`
* Vaincre un Pokémon → `20 – 140 EXP`
* Découvrir une île → `1 000 EXP`
* Battre un champion d'arène → `150 – 3 000 EXP`
* Réaliser des quêtes → `75 – 6 000 EXP`
