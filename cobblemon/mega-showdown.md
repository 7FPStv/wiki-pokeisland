# Mega Showdown

## MegaShowdown : Méga / Téra / Z-Moves / Dynamax

MegaShowdown ajoute des mécaniques “cosmiques” aux combats Cobblemon.

### Ce que ça change

* **Méga-Évolution** : ton Pokémon change de forme plus “puissante”.
* **Z-Moves** : un coup spécial “une fois” (selon la mécanique).
* **Téra** : tu changes le type de ton Pokémon en combat.
* **Dynamax** : ton Pokémon “grandit” et obtient un effet de combat spécial.

***

### Comment bien s’y prendre

1. Lance un combat.
2. Cherche l’option Méga/Téra/Z/Dynamax dans l’interface de combat.
3. Équipe ce qui est requis (objets/ressources correspondants).

***

{% hint style="info" %}
### Petits conseils de dresseur

Mega/Téra, ce n’est pas “juste pour faire joli” :

* ça change tes options de matchup,
* et ça peut retourner un combat si tu anticipes le type/stratégie.
{% endhint %}
