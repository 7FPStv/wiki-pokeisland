# Meubles (CobbleFurnies)

**CobbleFurnies** ajoute plus de **350 meubles et blocs de décoration** pour aménager ton île : un labo de professeur, un Centre Pokémon, une cuisine, une chambre… Les meubles se fabriquent tous dans un atelier dédié, le **Furni Crafter**, avec des matériaux simples (laine, planches, béton, calcite).

{% hint style="info" %}
Le mod n'est pas traduit en français : en jeu, les meubles portent leur **nom anglais** (*Red Chair*, *Light Fridge*, *Pikachu Statue*…). Cette page les cite donc sous ce nom pour que tu les retrouves facilement.
{% endhint %}

***

## Étape 1 : fabriquer le Furni Crafter

Le **Furni Crafter** se fabrique à l'établi :

| Ligne du haut | Ligne du bas |
| ----------------------- | ----------------------- |
| Cisailles + Hache en fer | 2 planches (n'importe quel bois) |

Pose-le, fais un **clic droit** dessus, choisis le meuble voulu : l'atelier affiche les matériaux nécessaires et les prend dans ton inventaire.

{% hint style="success" %}
Les quantités sont faibles : la plupart des meubles coûtent **un seul bloc** de laine, de planches ou de béton, parfois accompagné de deux bâtons ou d'un bloc de calcite.
{% endhint %}

## Ce que font les meubles

* **S'asseoir :** clic droit sur une chaise, un fauteuil, un canapé, un tabouret ou des toilettes.
* **Ranger :** frigo, congélateur, armoire, commode, table de chevet et placard mural ont un **inventaire**, comme un coffre.
* **Cuisiner :** fais un clic droit sur une **Stove** avec une **Marmite à feu** de Cobblemon en main pour cuisiner dessus.
* **Allumer :** clic droit sur une **Lamp** pour l'allumer ou l'éteindre. Elle réagit aussi à la redstone.
* **Ouvrir / fermer :** les rideaux, le frigo et les toilettes s'ouvrent d'un clic droit.
* **Changer de chaîne :** clic droit sur la **TV** (3 chaînes).

{% hint style="info" %}
**Personnaliser sans tout refaire :**

* clic droit sur une **table de chevet** avec n'importe quel bloc de **béton** pour changer sa couleur ;
* clic droit sur un **placard mural** avec une **vitre** pour changer sa forme.

Les éviers, plans de travail et supports muraux se **raccordent** automatiquement quand tu les poses côte à côte.
{% endhint %}

{% hint style="warning" %}
Le **frigo** et les **statues** font **deux blocs de haut** : laisse de la place au-dessus avant de les poser. La partie haute du frigo est le **congélateur** (*Freezer*), qui a son propre inventaire. Casser l'un ou l'autre te rend le frigo.
{% endhint %}
