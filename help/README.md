# Centre d'aide

## Centre d'aide de <mark style="color:$primary;">**PokeIsland**</mark>

<sup><mark style="color:$info;">Retrouve toutes les aides clés pour progresser et découvrir PokeIsland.<mark style="color:$info;"></sup>

PokeIsland est un serveur francophone sur **Minecraft Java Edition**, basé sur le mod **Cobblemon**. Capture, entraîne et fais évoluer tes Pokémon dans un monde unique.

{% hint style="warning" icon="bullhorn" %}
<mark style="color:$primary;">**Informations**</mark>

Pour jouer tu dois avoir un compte **Minecraft Java Editions** <sup><sub>(Ordinateur)<sub></sup>\
Le serveur n'est pas disponible sur **Bedrock Editions** <sup><sub>(Console, Tablette, etc.)<sub></sup>
{% endhint %}
