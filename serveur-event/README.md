# Événement

Le **serveur Event** est un **bonus**, complètement à part de l'aventure PokeIsland : ici, pas de progression, pas d'île ni de Pokémon à faire monter. On vient pour **se défouler** entre joueurs sur des **mini-jeux** développés par l'équipe : cache-cache, course, Pacman, concours de tenues, tournoi Cobblemon…

{% hint style="info" %}
Le serveur Event n'est **pas ouvert en permanence** : l'équipe et les animateurs l'ouvrent de temps en temps pour une animation. Ce que tu y gagnes (les coins des mini-jeux) reste sur le serveur Event et n'a aucun lien avec ton aventure.
{% endhint %}
