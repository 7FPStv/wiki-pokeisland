# Les mods

PokeIsland tourne sur **Minecraft 1.21.1 (Fabric)** avec **Cobblemon 1.7.2**. Autour de ça, une soixantaine de mods ajoutent du contenu, du confort et de la performance.

Tu n'as **rien à installer toi-même** : le [launcher PokeIsland](../informations/telechargement/) s'occupe de tout.

## Les mods maison

Trois mods sont développés spécialement pour le serveur.

### PokeIsland

Le mod central du serveur. Il apporte :

* la barre d'**[énergie](../pokeisland/energie.md)** et ses recharges,
* les **[Tickets de Safari](../pokeisland/pokeworld/safari.md)**,
* l'**[Œuf de marchand](../pokeisland/economie/oeuf-de-marchand.md)**,
* et surtout le **HUD PokeIsland**, entièrement personnalisable.

{% hint style="success" %}
**Le HUD se règle en jeu.** Une touche ouvre les *Paramètres PokeIsland*, où tu peux activer ou masquer :

* ton **argent**, ton **niveau**, ton **île**, tes **Pokémon capturés**
* les **FPS et le ping**
* ta **région actuelle**
* le **timer de Safari**
* les **événements à venir** et les **annonces**
* le suivi des **quêtes** (avec animations, et affichage dans le Tab)
* les alertes **Pokémon Légendaire**
{% endhint %}

### PokeIsland Cosmetic

Tout le contenu visuel et les objets exclusifs :

* les **[objets spéciaux](../pokeisland/objets-speciaux.md)** (cristaux, pierres, œufs, clés),
* les **coffres** (Vote, Dresseur, Expert, Champion, Événement),
* la **Pioche large** et la **Houe replanteuse**,
* des centaines de **blocs de décoration** : mobilier, plantes, guirlandes, matériel de camping, tentes, tableaux de quête, devantures de boutiques, Centre Pokémon…

### PokeIsland Ouray

Le mod compagnon du plugin qui gère la [Battle Factory](../pokeisland/battle-factory.md), la [Tour de combat](../pokeisland/tour-de-combat.md), les [raids](../pokeisland/raid.md), les [Piñatas](../pokeisland/pinata.md) et le [Ranked](../pokeisland/ranked.md).

## Les bibliothèques

Ces mods ne s'utilisent pas directement : ils font tourner les autres.

**Architectury**, **Fabric API**, **owo-lib**, **Cardinal Components**, **Cloth Config**, **YACL**, **Konkrete**, **Melody**, **SuperMartijn642 Config Lib**, **CorgiLib**, **TerraBlender**, **GeckoLib** (animations), **Athena** et **Prism** (rendu), **Iceberg**, **Accessories** et **Trinkets** (emplacements d'accessoires), **Impactor** (économie), **rctapi**, **MCEF** (navigateur intégré), **FerriteCore** (mémoire), **PacketEvents**, **Leukocyte**, **Spark** et **WorldEdit** (outils serveur).

{% hint style="info" %}
Si un de ces mods pose problème au lancement, c'est presque toujours un souci d'installation, pas de gameplay. Va voir la page [Résolution de problème launcher](../informations/telechargement/resolution-de-telechargement.md).
{% endhint %}
